# Financial Analysis Dashboard

## 1. Project Title

**Financial Performance & Transaction Analytics Dashboard**

## 2. Short Description / Purpose

An interactive Power BI analytics dashboard designed for **SS Finance** to monitor financial health, track transaction flows, and analyze revenue streams. The solution processes transactional data to deliver real-time visibility into overall volume, processing fees, tax liabilities, customer segment breakdowns, and transaction status distributions.

## 3. Tech Stack

* **Business Intelligence & Visualization:** Microsoft Power BI Desktop


* **Data Transformation & Modeling:** Power Query (ETL pipeline) & Relational Data Modeling


* **Analytical Expressions:** DAX (Data Analysis Expressions) for dynamic KPIs, YoY variance tracking, and conditional aggregations


* **Data Storage / Input:** Flat Files / CSV / SQL Database



## 4. Data Source

* SS Finance Transactional Dataset



## 5. Features & Highlights

### 📊 Core Financial KPIs & YoY Variance

* **Total Value:** **₹137.53M** in total transaction volume (+1.41% vs. Previous Year).


* **Transaction Count:** **14.94K** total transactions processed (-0.57% vs. Previous Year).


* **Average Ticket Size:** **₹9.20K** Average Transaction Value (+1.98% vs. Previous Year).


* **Revenue & Tax Collected:** **₹216.94K** in Total Fees (-0.17% YoY) and **₹39.04K** in Total Taxes (-0.26% YoY).



### 🏙️ Geographic & Customer Segmentation

* **State-Wise Breakdown:** Performance tracking across top states led by **Maharashtra (2.3K transactions)**, **Karnataka (1.8K)**, **Gujarat (1.7K)**, and **Tamil Nadu (1.5K)**.


* **Customer Segment Distribution:** Segmented by **Retail (8.1K)**, **Premium (2.8K)**, **SME (2.4K)**, **Corporate (1.0K)**, and **Wealth (0.6K)** tiers.


* **Gender Demographics:** Balanced distribution with **Male (52.0%)** and **Female (48.0%)** transaction shares.



### 💳 Transaction Breakdown & Status Monitoring

* **Transaction Types:** Detailed financial breakdown across categories such as Loan EMI (₹40.0M), Transfer (₹36.2M), Deposit (₹20.3M), Investment (₹15.1M), and Withdrawal (₹6.6M) with fee and tax itemization.


* **Status Tracking:** Real-time operational monitoring indicating **Success (85.8%)** vs. **Failed/Pending (14.2%)** rates.


* **Monthly Trends:** Line graph visualizing monthly volume fluctuations throughout the year, identifying peak activity in July.



### 📄 Detailed Granular Transaction Ledger

* Itemized transaction table tracking `Transaction_id`, `Customer Name`, `Transaction_type`, `Transaction_status`, `Customer_segment`, `State`, total amount, fees, and taxes for auditability.



### 🎛️ Dynamic Interactivity & Filtering

* Left-hand control panel with dropdown slicers for **Category**, **Occupation**, **Dynamic Metric Selection**, and **Year (2025)**.


* Navigation controls switching seamlessly between **Overview Analysis** and **Transactions** views.
